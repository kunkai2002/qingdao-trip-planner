# 青岛一图流 · 行程规划器

一张地图放下全部行程：景点、住宿、餐厅、娱乐和地铁。可编辑、可拖动、可自建路线、可导出备份。
界面为 **Apple Liquid Glass** 风格重构，全部图标为自绘 SVG —— 整个产品里没有任何 emoji。

原始版本是一个 713 行的单文件 HTML；这一版把它重构成 React + Vite 工程，并重做了视觉、动效与图标系统。

---

## 快速开始

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

构建产物在 `dist/`，是纯静态文件，可直接托管在任何静态服务器上。

## 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动构建并发布到 GitHub Pages。

`vite.config.js` 里 `base: './'` 让所有资源引用保持相对路径，因此同一份构建产物在
GitHub Pages 项目站点、用户站点或其它静态主机上都能直接用，不需要改配置。

## 设计系统

### Liquid Glass 材质

每一块玻璃由四层叠成，而不是单一的 `backdrop-filter: blur()`：

| 层 | 作用 |
| --- | --- |
| 本体 | 多段半透明渐变 + 细噪点（内联 SVG turbulence），避免看起来像塑料板 |
| 背景滤镜 | `blur` + `saturate` + `brightness`，让背后的地图透出并被提亮 |
| `::after` | 跟随指针的高光，加上从下方渗上来的柔和色彩映射 |
| `::before` | 1px 折射轮廓光（conic 渐变 + `mask-composite: exclude`），形成玻璃厚度感 |

层级顺序是「高光 → 内容 → 轮廓光」，所以高光永远不会压在文字上、吃掉对比度。

液体流动感来自 `glass--drift`：用注册过的 `@property` 缓慢转动 conic 渐变角度、平移高光位置。
只在大面板上开启 —— 重点是被封住的光在动，不是满屏东西都在动。

### 对比度

透明界面最容易翻车的地方。文字色板是按实测对比度选的，不是凭手感：

| Token | 浅色（典型玻璃底） | 深色（典型玻璃底） |
| --- | --- | --- |
| `--ink-1` | 14.4:1 | 14.3:1 |
| `--ink-2` | 6.2:1 | 8.4:1 |
| `--ink-3` | 4.9:1 | 5.0:1 |
| `--accent` | 6.5:1 | 5.6:1 |

全部达到或超过 WCAG AA。玻璃渐变最薄的中段不低于 0.5 不透明度，用来兜住地图繁杂处的对比度下限。

### 图标系统

`src/icons/registry.js` 是唯一的几何来源。图标存成数据（标签 + 属性），而不是 JSX，
因此同一份几何既能渲染成 React 元素，也能渲染成字符串给 Leaflet 的 `divIcon` 用 ——
地图上的图钉和面板里的按钮不可能画风走偏。

- 24×24 设计网格，安全边距约 13%
- 圆角线帽与圆角连接
- 颜色一律 `currentColor`，不内嵌背景、不写死尺寸
- **光学补偿**：小尺寸自动加粗描边（16px→2.0，24px→1.75，32px→1.6），保证视觉重量一致

```jsx
<Icon name="compass" size={20} />
<Icon name="star" size={16} state="selected" />
<Icon name="clipboardCheck" size={24} badge={3} />
```

### 动效

时长与缓动集中在 `src/lib/motion.js`（`tokens.css` 里有一份 CSS 镜像），所以按钮、卡片和
弹窗动起来像同一个物体的零件。弹簧全部低弹性 —— 玻璃有惯性，但不是果冻。

- 微交互 120–200ms · 悬停 160–240ms · 卡片 220–320ms · 弹窗 280–400ms
- 进场 `cubic-bezier(0.22, 1, 0.36, 1)`，离场 `cubic-bezier(0.4, 0, 1, 1)`
- 点击产生半透明折射波纹，而不是实色水波
- 分段控件用 `layoutId` 胶囊在选项间滑动并按文字宽度伸缩
- 完整支持 `prefers-reduced-motion`：关掉流动、视差与高光跟随，只留淡入淡出

**性能**：整个应用只有一个 document 级 `pointermove` 监听，按帧节流，且只写当前指针
下那一块玻璃的两个 CSS 变量 —— 不做逐组件监听，不触发 React 重渲染。
地图拖动时只提高玻璃底色不透明度，绝不每帧重跑大面积 `backdrop-filter`。

## 结构

```
src/
├── data/          点位、地铁线、路线、清单（纯数据）
├── icons/         图标注册表 + React 组件 + SVG 字符串生成 + 动效图标
├── lib/           坐标转换、动效常量、玻璃指针高光、本地存储
├── map/           Leaflet 实例与图钉图标
├── components/    玻璃基元、外壳、面板视图
├── store/         zustand 状态与持久化
└── styles/        tokens → glass → base → leaflet-theme
```

样式导入顺序是有意的：tokens 定义词汇，glass 定义材质，base 定义布局。
布局必须能覆盖材质（例如 `.panel { position: absolute }` 要压过 `.glass { position: relative }`），
两者选择器权重相同，只有源码顺序能决定胜负。

## 相比原版的改动

**数据**

- 注意事项从 `⚠` 前缀升级为独立的 `warn` 字段，配警示图标与配色，不再是文本里的一个符号
- 所有 emoji 从路线名、清单分组名里移除，换成图标名
- 字段名从 `n/c/r/rv/pr/ad/ar/tg/nt/bk` 改为可读名称，并保留 v1 数据迁移

**功能**

- 长按地图空白处新增点位（原版顶栏写了这个提示，但没有实现）
- 路线距离之外补上步行时间估算（含 1.32 绕路系数）
- 深色模式（自动 / 浅色 / 深色），地图栅格瓦片反色处理
- 底图可切街道 / 卫星，选择会被记住
- 备忘清单进度条，未完成项数显示在浮标徽章上
- 详情页可一键跳转高德导航
- `window.confirm / alert / prompt` 全部替换为可设计、可翻译的玻璃弹窗
- 键盘：`Esc` 关面板，`/` 聚焦搜索

**修掉的原版问题**

- 图钉尖端方向错了：`border-radius: 50% 50% 50% 2px` 配 `rotate(45deg)` 让尖角指向左侧而不是下方。
  正确写法是尖角在左下 + `rotate(-45deg)`，`iconAnchor` 才对得上真实坐标
- 搜索被图层过滤掉的点位仍会保留在路线里，现在按可见集合统一处理
- 桌面端面板会盖住右下浮标，现在面板打开时浮标与提示条自动让位

## 数据说明

数据源为携程 / Tripadvisor 点评均值加官方渠道。人均是非官方牌价，国庆期间普遍上浮；
点位坐标为近似值，可在地图上直接拖动修正。

所有改动只存在浏览器 `localStorage` 里，不会上传。换设备时用「导出备份」拿到 JSON，
在新设备「导入备份」即可。

底图为高德栅格瓦片。种子坐标是 WGS-84，首次加载时转换一次到 GCJ-02；
已经存进 localStorage 的坐标是转换后的，绝不能再转第二次。
