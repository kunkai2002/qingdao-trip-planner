## 一、这是什么

把一份 713 行的单文件 HTML（原件备份在
`D:\kun-workspace\backup\20260730-qingdao-map-source\`）重构成的地图行程规划器。
49 个点位分五类（景点/住宿/餐厅/娱乐/交通），8 条预设路线，可自建路线，
一份出行清单，可导出/导入 JSON。**所有数据只存在浏览器 localStorage，不上传任何服务器。**

视觉是 Apple Liquid Glass 风格，**全站零 emoji**，所有图标是自绘 SVG。

## 三、装成安卓 App（给使用者看的部分）

**用安卓手机的 Chrome 打开线上网址 → 菜单（右上⋮）→「安装应用」**，
或在应用内 **设置 → 装到手机上 → 安装到手机**。

装完之后：桌面有独立图标、全屏没有地址栏、在最近任务里是独立一个 App、
**而且会自动更新**（改完 push 就行，不用重装）。

### 为什么这样就够了

安卓上「已安装的 PWA」本来就是一个正经的启动器应用。之前我一直在讲的
**「7 天不用就清数据」是 Safari 的规则，安卓不适用**。安卓这边的风险是
「系统空间不足时清理」，对应的解法是 `navigator.storage.persist()`，
应用启动时和安装成功时都会申请一次，设置页会显示有没有拿到。

### 如果确实需要一个 .apk 文件

有一个手动触发的工作流 `.github/workflows/android-apk.yml`：
GitHub → Actions → **Build Android APK** → Run workflow，
跑完在该次运行的 Artifacts 里下载 APK。

本机没有 JDK / Android SDK，所以只能在 CI 里构建（Ubuntu runner 自带）。

⚠️ **签名**：没有配 `ANDROID_KEYSTORE` secret 时会用一次性密钥，
**装得上，但下次构建的版本无法覆盖安装**（安卓拒绝不同密钥的更新），要先卸载。
要长期用就得生成一个固定 keystore 并存成仓库 secret（`ANDROID_KEYSTORE` 存 base64、
`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_PASSWORD`、`ANDROID_KEY_ALIAS`）。
**密钥绝不提交进仓库。**

## 五、🔴 铁律（改之前一定要看）

### 1. 样式导入顺序有意义
`main.jsx` 必须 **tokens → glass → base → leaflet-theme**。
`.glass{position:relative}` 和 `.panel{position:absolute}` 权重相同，
**只有源码顺序决定胜负**。顺序错了面板会变成 relative 跑到左上角。

### 2. 改玻璃底色，必须同步检查 `@supports` 降级块
控件是**深色玻璃**、文字是**浅色**。`glass.css` 里
`@supports not (backdrop-filter)` 的降级如果写成白色，
**不支持 backdrop-filter 的浏览器会整个 UI 白底白字**（已经踩过一次）。

### 3. 文字颜色按实测对比度选，不要凭手感
最坏情况＝最薄的 `--g-tint-b`(0.80) 叠在白色地图高光上。
现值：ink-1 8.5 / ink-2 5.4 / ink-3 4.7 / accent 4.9，全部过 WCAG AA。
**`--g-tint-b: 0.80` 是承重的**，为了更透而调低会静默破坏次级文字。

### 4. 图钉尺寸和 `iconAnchor` 必须一起改
图钉是 24×24 方块转 -45°，半对角线 16.97，尖端落在 (14, 29)，
所以 `iconSize [28,32]`、`iconAnchor [14,29]`。
**改一个不改另一个，49 个点会全部偏离真实坐标。**

### 5. 跨图钉层级只能用 `setZIndexOffset()`
Leaflet 把 z-index 内联写在父层 `.leaflet-marker-icon` 上（**由纬度推导**），
`.pin` 上的 `z-index` **永远不起作用**。偏南的图钉会盖住选中的偏北图钉。

### 6. 坐标：WGS-84 → GCJ-02 只转一次
种子点位是 WGS-84，首次加载转一次。
**localStorage 里存的已经是转换后的，绝不能再转第二次。**
定位（`navigator.geolocation`）拿到的是 WGS-84，**必须过 `wgs2gcj` 再用**，
否则蓝点偏几百米。

### 7. 搜索：先比文字，再看图层
`lib/search.js`。图层开关只决定**画不画**，不参与匹配 ——
否则「上次关掉的图层」会让今天的搜索静默返回 0 且不说明原因。
被图层挡住的命中要显示出来并提供一键恢复。

### 8. 不要用 `AnimatePresence mode="wait"` 闸门内容切换
它让正确性依赖动画完成，还给每次切面板加延迟。
内容切换用 keyed 元素 + fade-in；`mode="wait"` 只用于换单个图标这类纯装饰。

### 9. 验证时：帧冻结会骗你（已踩四次）
`getBoundingClientRect()` 在动画进行中会量到中间值
（44px 量成 41px、opacity 量成 0.11），`AnimatePresence` 退场会让元素多留一会儿，
程序化 `scrollLeft` 不触发 scroll 事件。
**先注入 `transform:none!important;opacity:1!important` 再量；
状态一律看 `window.__store.getState()`，不要看 DOM 里还在不在。**

DEV 下有三个把手专供验证：`window.__map`、`window.__mapApi`、`window.__store`
（`import.meta.env.DEV` 保护，不会进线上产物）。

### 10. 改代码只用 Edit/Write
禁用 PowerShell `Get-Content | Set-Content`（会毁非 ASCII 字符，
`-Encoding utf8` 还塞 BOM）。确实要按字节改就用
`[IO.File]::WriteAllText($p,$t,(New-Object Text.UTF8Encoding($false)))`。
自查扫 `�`，**别扫 `??`**（JS 空值合并会大量误报）。

## 六、关键设计决定（以及为什么）

| 决定 | 原因 |
| --- | --- |
| 控件用**深色玻璃**，两个主题都是 | 浅色玻璃叠在浅色地图上完全没有对比，折射/轮廓光全看不见，成品就是「白色圆角塑料片」。深色玻璃自带对比，因为地图永远比它亮。**主题开关因此只控制地图**。 |
| 图钉**浅底彩色图标**，只有选中/路线站点/移动中才填充 | 49 个高饱和色块会跟地图抢注意力。让颜色有意义：响度跟随相关性。 |
| **自写像素网格聚合**，不用 leaflet.markercluster | 它会接管 marker 所有权，打烂现有的 reconcile-by-id 与图标状态逻辑。 |
| 标签**限量**（zoom≥14、最多 14 个、带碰撞规避） | 49 个名字同时出现就是一堵文字墙。 |
| 点位默认**不可拖动**，要按「调整位置」武装 | 原本全部 `draggable:true`，拖点会抢掉地图平移，还容易误移。 |
| 弹窗自己实现，不用 `window.confirm/prompt` | 原生弹窗无法设计、无法翻译，且会打破玻璃质感。 |
| 手机 sheet **固定高度再平移**，不是内容自适应 | 多档位（peek/half/full）只有这样才做得出来。地图应用里**面板背后就是内容**。 |

## 九、能撑多久

- **主机**：GitHub Pages 公开仓库免费、**没有到期日**。额度是 1GB 容量、
  每月 100GB 流量，本站 ~0.55MB，差得远。
- **最可能先坏的**：高德瓦片（见上）。
- **数据**：只在这台设备的浏览器里。装成 App + `storage.persist()` 之后
  安卓不会随便清，但**换手机、清数据、卸载都会没**。
  真正的保险是定期「导出备份」把 JSON 存到别处。
- **不会烂的**：构建产物完全自包含（没有 CDN、Leaflet 打进 bundle、用系统字体），
  已部署的版本几年后照样能开；只有「重新 build」会随生态变化而变难。
